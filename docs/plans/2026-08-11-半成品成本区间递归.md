# 半成品成本区间递归 实现计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让菜谱成本区间趋势的 min/max/avg 三档基于同一组价格源计算，保证 `min ≤ avg ≤ max` 恒成立，且半成品价格波动能递归传导进区间。

**Architecture:** 新增递归函数 `calculate_recipe_cost_range_as_of`，每个食材按统一 5 层降级链（direct→fallback→name_match→recipe→contains）产出 `(min, max, avg)` 三档，三档统一归算到「元/克」口径后乘用量克数得成本；菜谱总成本三档各自求和。`calculate_recipe_cost_range_trend` 逐天循环从「双轨（avg 调 as_of + 手写 min/max）」收敛为「单轨调一次 range 函数」。设计依据见 [2026-08-11-半成品成本区间递归-design.md](2026-08-11-半成品成本区间递归-design.md)。

**Tech Stack:** Python + FastAPI + SQLAlchemy，Decimal 精度，SQLite 开发库（主仓库 `d:/code/live_calc/backend/data/livecalc.db`）。

## 关键设计决策（实现时必须遵守）

1. **三档同口径（元/克）**：每个来源产出的 min/max/avg 都先归算到「元/克」，再乘 `qty_grams` 得成本。绝不出现「min/max 走 per_gram、avg 走 standard_unit」的错位——这正是原 bug 根源。
2. **降级链 1:1 映射 avg 路径**：range 函数内部降级顺序与 [recipe_service.py:1994-2101](../../backend/app/services/recipe_service.py#L1994) 的 `calculate_recipe_cost_as_of` 完全一致（direct→fallback→name_match→recipe→contains），命中的**第一个**有效来源同时产出三档。
3. **脏数据过滤（取舍 B）**：极值计算过滤 `price is None or price <= 0 or standard_quantity is None or standard_quantity <= 0` 的记录（防 min=0）。过滤后池空则该来源视为无效，继续降级；不动数据本身。
4. **用量取 max（现状沿用）**：`_get_effective_quantity` 对 quantity_range 返回 max（注释「取平均」失实，但本次不改），三档用量一致。
5. **半成品递归**：新增 `_get_cost_from_recipe_range`，复用 `_get_cost_from_recipe` 的 `visited` 循环检测 + `_serving_weight_to_grams` 份重桥接骨架，把「调 `calculate_recipe_cost_as_of` 拿单点」换成「调 `calculate_recipe_cost_range_as_of` 拿三档」，再 `÷ total_yield_g` 转每克三档单价。
6. **数学保证**：对单个食材，`min_i ≤ avg_i ≤ max_i`（同一记录集的极值 vs 加权/代表值），求和后总体 `min ≤ avg ≤ max` 恒成立。

```python
def calculate_recipe_cost_range_as_of(
    db: Session,
    recipe_id: int,
    user_id: int,
    as_of_date: datetime,
    visited: Optional[List[int]] = None,
    tz: str = "UTC",
) -> Optional[dict]:
    """计算菜谱在某天的成本三档（min/max/avg），三档基于同一组价格源。

    返回 {min_cost, max_cost, avg_cost, currency, cost_breakdown} 或 None（菜谱不存在）。
    保证 min_cost ≤ avg_cost ≤ max_cost（每个食材三档同源同口径、求和保号）。

    降级链与 calculate_recipe_cost_as_of 1:1 对齐：
    direct → fallback → name_match → recipe(半成品递归) → contains(聚合)。
    """
    if visited is None:
        visited = []
    if recipe_id in visited:
        return None  # 循环检测
    visited = visited + [recipe_id]

    recipe = db.query(Recipe).filter(Recipe.id == recipe_id, Recipe.is_active == True).first()
    if not recipe:
        return None
    ingredients = (
        db.query(RecipeIngredient)
        .filter(RecipeIngredient.recipe_id == recipe_id)
        .all()
    )

    total_min = Decimal("0")
    total_max = Decimal("0")
    total_avg = Decimal("0")
    breakdown = []

    for ri in ingredients:
        ing = ri.ingredient
        if not ing:
            continue
        imin, imax, iavg, src = _ingredient_cost_range(
            db, ri, ing, user_id, as_of_date, visited, tz
        )
        total_min += imin
        total_max += imax
        total_avg += iavg
        breakdown.append({
            "ingredient_id": ing.id,
            "name": ing.name,
            "min_cost": float(imin),
            "max_cost": float(imax),
            "avg_cost": float(iavg),
            "cost_source": src,
        })

    return {
        "min_cost": total_min,
        "max_cost": total_max,
        "avg_cost": total_avg,
        "currency": "CNY",
        "cost_breakdown": breakdown,
    }


def _ingredient_cost_range(
    db: Session,
    recipe_ingredient: RecipeIngredient,
    ingredient: Ingredient,
    user_id: int,
    as_of_date: datetime,
    visited: List[int],
    tz: str,
) -> tuple:
    """单个食材的成本三档 + 来源标签。

    返回 (min_cost, max_cost, avg_cost, cost_source)。
    全部来源无价时返回 (Decimal(0), Decimal(0), Decimal(0), "no_price")。
    """
    # 用量统一归克（复用 _get_effective_quantity + 单位转克）
    qty_decimal, qty_unit_id = _get_effective_quantity(recipe_ingredient)
    qty_g = _qty_unit_to_grams(db, ingredient, qty_decimal, qty_unit_id)
    if qty_g is None or qty_g <= 0:
        return Decimal("0"), Decimal("0"), Decimal("0"), "no_quantity"

    # ---- 来源 1：direct 直接商品 ----
    direct = _direct_cost_range_ppg(db, ingredient, user_id, as_of_date, tz)
    if direct is not None:
        mn_ppg, mx_ppg, av_ppg = direct
        return (mn_ppg * qty_g, mx_ppg * qty_g, av_ppg * qty_g, "direct")

    # ---- 来源 2: fallback / 来源 3: name_match / 来源 4: recipe / 来源 5: contains ----
    # Task 3/4/5 依次填入，此处先留占位 return
    return Decimal("0"), Decimal("0"), Decimal("0"), "no_price")


def _direct_cost_range_ppg(
    db: Session, ingredient: Ingredient, user_id: int, as_of_date: datetime, tz: str
) -> Optional[tuple]:
    """直接商品的 (min_ppg, max_ppg, avg_ppg)，单位元/克。无可用记录返回 None。

    avg：复用 resolve_direct_weighted_for_cost 的加权价，折回元/克。
    min/max：取所有参与商品当天（前向填充）记录的 per_gram 极值，过滤脏数据。
    """
    from app.services.ingredient_price_service import resolve_direct_weighted_for_cost

    dw = resolve_direct_weighted_for_cost(
        db, ingredient.id, user_id=user_id, as_of_date=as_of_date, tz=tz
    )
    if dw is None:
        return None
    unit_price, participants, std_unit_id = dw
    # 加权价是「元/standard_unit」，折回元/克
    av_ppg = _std_unit_price_to_per_gram(db, ingredient, unit_price, std_unit_id)
    if av_ppg is None:
        return None

    # 收集所有参与商品当天记录的 per_gram
    ppgs = []
    for p in participants:
        pid = p.get("product_id") if isinstance(p, dict) else getattr(p, "product_id", None)
        if not pid:
            continue
        recs = _get_price_records_with_fallback(
            db=db, user_id=user_id, product_id=pid, as_of_date=as_of_date, tz=tz
        )
        for r in recs or []:
            if _is_dirty_record(r):
                continue
            ppg = _convert_record_to_price_per_gram(db, r, user_id=user_id)
            if ppg is not None and ppg > 0:
                ppgs.append(ppg)

    if not ppgs:
        # 加权有值但拆不出单条极值（罕见）：三档相等兜底
        return (av_ppg, av_ppg, av_ppg)
    return (min(ppgs), max(ppgs), av_ppg)
```

```python
def _is_dirty_record(record) -> bool:
    """脏数据判定：price 缺/≤0 或 standard_quantity 缺/≤0。极值计算时跳过。"""
    if record is None:
        return True
    if record.price is None or Decimal(str(record.price)) <= 0:
        return True
    if record.standard_quantity is None or Decimal(str(record.standard_quantity)) <= 0:
        return True
    return False


def _std_unit_price_to_per_gram(
    db: Session, ingredient: Ingredient, price_per_std_unit: Decimal, std_unit_id: Optional[int]
) -> Optional[Decimal]:
    """元/standard_unit → 元/克。用 UnitConversionService 折算。"""
    if price_per_std_unit is None or std_unit_id is None:
        return None
    gram_unit = db.query(Unit).filter(Unit.id == 3).first()
    std_unit = db.query(Unit).filter(Unit.id == std_unit_id).first()
    if not gram_unit or not std_unit:
        return None
    ucs = UnitConversionService(db)
    converted = ucs.convert(
        Decimal(str(price_per_std_unit)),
        std_unit.abbreviation,
        gram_unit.abbreviation,
        entity_type="ingredient",
        entity_id=ingredient.id,
    )
    if converted:
        return Decimal(str(converted[0]))
    return None


def _qty_unit_to_grams(
    db: Session, ingredient: Ingredient, qty: Optional[Decimal], unit_id: Optional[int]
) -> Optional[Decimal]:
    """把 (数量, 单位) 归算到克。已是克/无单位直接返，否则 UnitConversionService。"""
    if qty is None:
        return None
    q = Decimal(str(qty))
    if unit_id is None or unit_id == 3:
        return q
    unit = db.query(Unit).filter(Unit.id == unit_id).first()
    gram_unit = db.query(Unit).filter(Unit.id == 3).first()
    if not unit or not gram_unit:
        return None
    ucs = UnitConversionService(db)
    converted = ucs.convert(
        q, unit.abbreviation, gram_unit.abbreviation,
        entity_type="ingredient", entity_id=ingredient.id,
    )
    if converted:
        return Decimal(str(converted[0]))
    return None
```

```python
def _records_cost_range_ppg(records, db: Session, user_id: int) -> Optional[tuple]:
    """一组记录 → (min_ppg, max_ppg, avg_ppg)，过滤脏数据。池空返回 None。

    avg 取记录 per_gram 的简单平均（记录集代表值）。
    由于 min/max 是同一记录集极值，min≤avg≤max 必然成立。
    """
    ppgs = []
    for r in records or []:
        if _is_dirty_record(r):
            continue
        ppg = _convert_record_to_price_per_gram(db, r, user_id=user_id)
        if ppg is not None and ppg > 0:
            ppgs.append(ppg)
    if not ppgs:
        return None
    avg_ppg = sum(ppgs) / Decimal(len(ppgs))
    return (min(ppgs), max(ppgs), avg_ppg)


def _fallback_cost_range_ppg(
    db: Session, ingredient: Ingredient, user_id: int, as_of_date: datetime, tz: str
) -> Optional[tuple]:
    """fallback 链（substitutable 同理）：回退食材当天记录集的 (min,max,avg) ppg。"""
    fb = _get_ingredient_fallback(db, ingredient, user_id)
    if not fb:
        return None
    fb_ingredient, _latest, _chain = fb
    # 取回退食材所有活跃商品当天记录
    products = db.query(Product).filter(
        Product.ingredient_id == fb_ingredient.id, Product.is_active == True
    ).all()
    all_recs = []
    for p in products:
        recs = _get_price_records_with_fallback(
            db=db, user_id=user_id, product_id=p.id, as_of_date=as_of_date, tz=tz
        )
        all_recs.extend(recs or [])
    return _records_cost_range_ppg(all_recs, db, user_id)
```

```python
def _get_cost_from_recipe_range(
    db: Session,
    ingredient: Ingredient,
    user_id: int,
    as_of_date: datetime,
    visited: Optional[List[int]] = None,
    tz: str = "UTC",
) -> Optional[tuple]:
    """半成品推导的 (min_ppg, max_ppg, avg_ppg)，单位元/克。无制作菜谱/循环返回 None。

    与 _get_cost_from_recipe 同骨架：找制作菜谱 → visited 循环检测 →
    servings × serving_weight 算产量克 → 递归 calculate_recipe_cost_range_as_of
    拿三档总成本 → ÷ 产量克 得每克三档单价。
    """
    if not ingredient:
        return None
    making_recipe = db.query(Recipe).filter(
        Recipe.result_ingredient_id == ingredient.id, Recipe.is_active == True
    ).first()
    if not making_recipe:
        return None
    if visited is None:
        visited = []
    if making_recipe.id in visited:
        return None  # 循环检测
    visited = visited + [making_recipe.id]

    sw_g = _serving_weight_to_grams(db, ingredient)
    if not sw_g or sw_g <= 0:
        return None
    total_yield_g = Decimal(str(making_recipe.servings or 1)) * sw_g
    if total_yield_g <= 0:
        return None

    rng = calculate_recipe_cost_range_as_of(
```

结构对齐 `_get_aggregated_cost_from_children`（[recipe_service.py:389](../../backend/app/services/recipe_service.py#L389)），但每个子食材要拿三档 ppg：

```python
def _contains_cost_range_ppg(
    db: Session, ingredient: Ingredient, user_id: int, as_of_date: datetime,
    visited: Optional[List[int]] = None, tz: str = "UTC",
) -> Optional[tuple]:
    """CONTAINS 子食材按 strength 加权的 (min,max,avg) ppg。无子食材/全无价返回 None。

    对每个子食材调 _get_child_price_per_gram_range 拿三档 ppg，
    再按 strength 加权（与 _get_aggregated_cost_from_children 同公式）。
    """
    hierarchies = db.query(IngredientHierarchy).filter(
        IngredientHierarchy.parent_id == ingredient.id,
        IngredientHierarchy.relation_type == HierarchyRelationType.CONTAINS.value,
    ).order_by(IngredientHierarchy.strength.desc()).all()
    if not hierarchies:
        return None

    triples = []  # (min_ppg, max_ppg, avg_ppg, strength, name)
    total_strength = 0
    for h in hierarchies:
        if not h or not h.child:
            continue
        r = _get_child_price_per_gram_range(db, h.child, user_id, as_of_date, visited, tz)
        if r is None:
            continue
        strength = h.strength or 50
        triples.append((*r, strength, h.child.name))
        total_strength += strength
    if not triples:
        return None

    def _weighted(idx):
        if total_strength > 0:
            return sum(t[idx] * Decimal(str(t[3])) for t in triples) / Decimal(str(total_strength))
        return sum(t[idx] for t in triples) / Decimal(len(triples))

    names = ", ".join(t[4] for t in triples)
    return (_weighted(0), _weighted(1), _weighted(2), f"{ingredient.name} ← 子食材({names})")


def _get_child_price_per_gram_range(
    db: Session, ingredient: Ingredient, user_id: int, as_of_date: datetime,
    visited: Optional[List[int]] = None, tz: str = "UTC",
) -> Optional[tuple]:
    """子食材的 (min,max,avg) ppg——复用 _get_child_price_per_gram 的遍历顺序，
    但每个分支取三档。实现上优先调 _ingredient_cost_range 的单食材逻辑（DRY）：
    构造一个最小 RecipeIngredient 代理取用量，或直接抽 _ingredient_cost_range 的
    ppg 段为独立函数复用。

    简化方案：直接对子食材也走 _ingredient_cost_range 的 ppg 三档计算（不含本次 recipe_ingredient
    的用量乘法），用 1 克作为占位用量。
    """
    # 子食材聚合里取「每克单价」，用量用 1 克占位
    class _StubRI:
        def __init__(self, ing):
            self.ingredient = ing
            self.quantity = None
            self.quantity_range = None
            self.unit = None
            self.unit_id = None
            self.original_quantity = None
    mn, mx, av, src = _ingredient_cost_range(
        db, _StubRI(ingredient), ingredient, user_id, as_of_date, visited or [], tz
    )
    # _ingredient_cost_range 返回的是成本（已 × qty_g=1g），数值上即 ppg
    if src == "no_price" or src == "no_quantity":
        return None
    return (mn, mx, av)
```

> **实现注意**：`_StubRI` 占位用法要求 `_get_effective_quantity` 对 quantity=None 的 stub 能走 original_quantity/quantity_range 分支并最终给出克数。若 stub 触发 no_quantity 分支（quantity 为 None → 0），则需改用「子食材默认 100g」等规则——参考 `_get_child_price_per_gram`（[recipe_service.py:318](../../backend/app/services/recipe_service.py#L318)）现状对子食材用量的处理，1:1 对齐。最干净的做法是**抽 `_ingredient_cost_range` 的 ppg 计算段为独立 `_ingredient_ppg_range(...)`**，让 recipe_ingredient 用量和 contains 子食材共用 ppg 段、各自只管乘用量。若发现 stub 方案不稳，改成抽函数。

```python
def _ppgs_to_range(ppgs):
    """一组每克单价 → (min, max, avg)，池空返回 None。"""
    clean = [Decimal(str(p)) for p in ppgs if p is not None and Decimal(str(p)) > 0]
    if not clean:
        return None
    avg = sum(clean) / Decimal(len(clean))
    return (min(clean), max(clean), avg)
```
