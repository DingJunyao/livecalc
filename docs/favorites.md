# 我的收藏

看到常用的原料、常买的商品、爱做的菜谱、常去的商家，都可以**收藏**起来：列表更快找到、推荐更懂你。

## 怎么收藏

- **列表行**：原料 / 商品 / 菜谱列表每行都有心形按钮，点一下即收藏（再点取消）
- **详情页**：标题栏有同样的收藏按钮
- 商家收藏一直就有（商家列表 / 详情页），现在和其它三类收在同一个聚合页里

## 列表里的收藏

- 筛选栏有**「仅看我的收藏」**开关，只看收藏项
- 收藏项在列表中**置顶**，但组内顺序保持原排序（按时间 / 名称等）不受影响，翻页不重不漏

## 收藏聚合页

侧边栏「我的收藏」进入聚合页，四个标签页（原料 / 商品 / 菜谱 / 商家）集中管理所有收藏：按收藏时间倒序排列，点条目直接进详情，取消收藏即从列表移除。

## 推荐联动

收藏是今日推荐的偏好信号之一——你收藏的菜谱、以及含收藏原料的菜，会被**优先考虑**（见 [今日推荐](recommend.md)）。

## 生命周期

- 合并原料 / 商品时，被合并方的收藏会被移除（与商家合并同口径，不会重复收藏）
- 实体被软删时收藏保留但不再显示；实体恢复后收藏自动回来
- **数据导出包含收藏**，导入时按 id（找不到时按名字）重新映射——迁移设备收藏不丢
- 本地模式同样支持

> 收藏是你的**私有数据**，即时生效、不需要审核。
