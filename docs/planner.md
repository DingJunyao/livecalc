# 试算

不想等系统推荐，想自己搭一餐、甚至安排一整天的吃法？**试算**页就是干这个的：把菜谱、原料、商品自由组合成「方案」，实时看**成本与营养素合计 vs 目标**，还能回看这套搭配按历史价格算的成本走势，满意了就**设为今日推荐**。

## 方案：一顿 / 一日

方案分两种类型：

- **一顿**：搭配单独一餐。目标是每日目标的按餐折算（早餐 / 午餐 / 晚餐各占不同比例），预算同比例缩放
- **一日**：安排早 / 午 / 晚三餐（加「其他」分组）。目标就是你在个人中心设的每日营养目标与预算

## 搭配条目

方案里可以加三类条目：

- **菜谱**：从菜谱库搜索添加，可改**份量**（成本与营养随份量缩放）
- **原料**：搜索原料添加，填**数量 + 单位**（单位与计价单位不一致时自动折算）
- **商品**：搜索商品添加，按最新有效记录的单价 × 数量计价

宽屏下条目以多列卡片展示，点条目名称可直接跳到对应的菜谱 / 原料 / 商品详情页。

## 合计 vs 目标

编辑器底部实时给出**成本 + 核心营养素（能量 / 蛋白质 / 脂肪 / 碳水）的合计与目标对比**，一眼看出这餐吃超了还是没吃够。

## 成本走势与分析

已保存的方案可以看：

- **成本走势**：按历史价格 as-of 逐日折算（30 / 90 / 365 天区间可选），带价格区间带——这套搭配在上个月做要花多少钱，一目了然
- **成本占比**：各条目对总成本的贡献（与菜谱分析页同款图表）
- **营养成分**：全部营养素 + NRV%，以及各条目的营养来源明细（与菜谱详情的营养组件同款）

## 与今日推荐联动

- **拿去试算**：今日推荐的某餐想自己调整？点推荐卡片上的「拿去试算」，这餐的菜谱会带入试算页作为起点
- **设为今日**：试算页一键把方案设为当天的推荐（一顿方案需选餐次，一日方案设三餐）。推荐页会以「方案视图」渲染这套搭配，含每个条目和单条成本；之后点「换整餐」，该餐恢复为 AI / 规则推荐

方案列表的每张卡片显示成本、核心营养素（含 NRV）和 30 天成本迷你图。

## 隐私与本地模式

方案是你的**私有数据**，仅本人可见可改。本地模式同样支持（数据存在 IndexedDB，导出导入包含方案）。
