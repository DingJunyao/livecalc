# 移动 App

生计的移动 App 是原生的手机应用，连接你自己部署的生计服务器使用。功能与网页端**保持一致**（价格记录、菜谱、原料商品、收藏、试算、今日推荐、多币种……），并针对手机做了原生体验：底部导航、扫码记价、断网排队补传等。

> App 目前需从源码自行构建安装，尚未发布到应用商店。功能说明默认与[网页端文档](README.md)同口径，这篇只讲 App 特有的部分；各功能的详细用法请看对应的功能手册。

## 获取与安装

前提：你已经部署好了生计服务器（见 [部署](admin/deploy.md)），手机与服务器网络可达。

App 使用 Flutter 开发，从源码构建：

```bash
cd mobile
flutter pub get
flutter build apk --release   # Android
```

生成的 APK 在 `mobile/build/app/outputs/flutter-apk/` 下，传到手机安装即可。iOS 需要用 Xcode 打开 `mobile/ios/` 自行签名安装（Developer 模式下直接跑 `flutter run --release` 也行）。

> 构建环境要求见 `mobile/` 目录（Flutter SDK ^3.5）。桌面端（Windows/macOS/Linux）目录同样存在，按需自行构建，但移动 App 是主要维护对象。

## 首次使用

1. **配置服务器**：首次打开会进入服务器配置页，填入你部署的生计服务地址（即浏览器访问网页端用的地址，如 `https://livecalc.example.com`），点测试连接确认可达
2. **登录**：使用与网页端**相同的账号**登录（同一个后端，数据互通；也可以在 App 里直接注册）
3. 登录后进入首页（今日推荐）

> 服务器地址后续可以改：登录页会显示当前服务器，点它可重新配置。

## 界面与导航

App 是自适应布局，手机竖屏（窄屏）用**底部标签栏**，平板 / 横屏 / 桌面（宽屏）用**侧边导航栏**，入口一致：

- **首页**：今日推荐（三餐 + AI 组合）
- **价格**：价格记录列表，含快速填写、粘贴导入入口
- **菜谱**：菜谱浏览与详情
- **更多**（仅窄屏）：原料、商品、商家、我的收藏、试算、个人中心

各二级页面左上角都有返回按钮；列表支持搜索、筛选与无限滚动。

## 移动端特色

### 主屏快捷方式

长按手机桌面上的「生计」图标，可以直接进入三个常用入口（iOS、Android 都支持，与网页端 PWA 的快捷方式对齐）：

| 快捷方式 | 进入页面 |
|---|---|
| 计价 | 价格记录列表（[价格记录](prices.md)） |
| 每日推荐 | 首页今日推荐（[今日推荐](recommend.md)） |
| 菜谱 | 菜谱列表（[菜谱与成本](recipes.md)） |

- 标题跟随 App 界面语言（简体中文 / English / العربية）。
- 未登录时点击会先进入登录页，登录成功后自动跳到对应页面。
- 平台差异：Android 的快捷方式在安装后即可用；iOS 是动态注册的，需要先启动过一次 App 才会出现（之后即使杀掉 App 也保留）。

### 扫码

记价表单和商品搜索都带扫码入口：扫商品条码，命中本库商品自动填入；查到了商品信息但库里没有时，会询问是否按条码新增商品（需要管理员配置条码服务，见 [后台管理 · 条码服务配置](admin/admin-pages.md#条码服务配置)）。

### 断网排队

手机离线时，记价等**写操作**会先存进手机本地的待同步队列；恢复联网后自动重放补传，不需要你手动重试。列表数据在联网时实时加载，App 不提供完整的离线浏览。

### 多语言

App 支持**简体中文 / English / العربية**（阿拉伯语界面自动从右到左），跟随系统语言；多币种（含印尼盾等外币的原币记价与汇率折算）与网页端同口径。

## 常见问题

- **连不上服务器**：确认地址填法（含 `https://`，端口照网页端地址），且手机与服务器在同一网络或服务器公网可达。用自签名证书的 HTTPS 或纯 HTTP 地址时，部分手机系统会限制 App 访问，建议用正常签名的域名。
- **登录后数据不对**：App 与网页端共用同一账号与数据，检查是否登错了服务器或账号。
- **离线记的价没出现**：等网络恢复后 App 会自动补传；也可以重启 App 触发一次同步。
